# T194 — ファイル文字起こしの行でも、行頭の話者名の付け札を落とす

> **状態:** 完了 — 2026-10-12
> **台帳:** [docs/tasks/backlog.md](./backlog.md)
> **関連:** [T188](./T188-final-pass-context-prompt.md) D6（ライブの確定行で付け札を落とした）、REQ-TRX-LIVE-20

## 1. 目的

Whisper が行頭に付ける `(山本)` のような話者名の付け札を、ファイル文字起こしの行からも落とす。ライブ（T188）と同じ規則にそろえる。

## 2. 計測（2026-10-12）

スクラッチの検証プログラムで、T182 の `ma02`（15.8 分の実際の会議）を 16kHz の WAV にし、本体の `TranscribeFileAsync`（small・GPU）で文字起こしした。

| 経路 | 行 | 行頭に付け札がある行 |
|---|---|---|
| 話者識別なし | 320 | **50（16%）** |
| 話者識別あり | 320 | **50（16%）** — `[話者1] (山本)…` のように、話者欄と食い違う名前が並ぶ |

例: `[00:01:10 - 00:01:13] [ファイル] [話者1] (高川)いっこよくない。`（実際の会議に「高川」はいない）

## 3. スコープ境界

**やること**
- ファイル文字起こしの 2 経路（話者識別なし `ProcessFileChunkAsync`・あり `CollectTranscriptSegmentsAsync`）で、ライブと同じ `StripSpeakerTag` を通す。付け札だけの行は出さない

**やらないこと（重要）**
- **付け札の判定規則は変えない**（REQ-TRX-LIVE-20 と同じ。空白を含まない 1〜10 文字の丸括弧書き）
- **出力の書式（REQ-TRX-07 / REQ-TRX-DIA-06）は変えない**

## 4. 決定事項

| # | 決定 | 結論 |
|---|---|---|
| D1 | 落とすか | **落とす。** 16% の行に付き、話者識別ありでは話者欄と食い違う。存在しない名前を成果物に残すのは誤った情報になる（T188 D6 と同じ理由） |
| D2 | 話者識別ありの経路 | 本文から落とす。トークンの時刻（REQ-TRX-DIA-13。話者の重なりの計算に使う）はそのまま — 付け札のトークンは行頭の短い区間で、重なりへの影響は小さい |
